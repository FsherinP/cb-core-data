Engineering reference · branch cbrelease-4.8.39.3

Every job in the Karmayogi Bharat data pipeline, mapped end to end.

A three-stage PySpark + DuckDB batch pipeline that turns raw platform activity (Cassandra, Elasticsearch, Redis, MongoDB, Druid, Postgres) into 43 requirement-specific reports, a Postgres/BigQuery data warehouse, and the live Redis cache behind the admin dashboard. This page inventories what every job reads, joins, computes and writes — built for someone opening this repository for the first time.

Reflects the current cbrelease-4.8.39.3 branch (as of 2026-08-24), built on top of the earlier cbrelease-4.8.39.1-hotfix analysis with 3 new org-hierarchy/warehouse utility jobs and 9 files updated in between. One clarification worth having: a performance-profiling / phase-clocking instrumentation layer exists, but only on a separate cbrelease-4.8.39.1-profiling branch that was never merged into this lineage — it is not present anywhere in this branch, so nothing was excluded here.

How data moves through the system

Stage 0 pulls everything raw into Parquet caches. Stage 1 joins those caches into a handful of reusable "computed" tables. Stage 2 is ~40 independent jobs, each reading the computed tables to build one report, warehouse table, or cache entry. Click any box to jump to its detail.
